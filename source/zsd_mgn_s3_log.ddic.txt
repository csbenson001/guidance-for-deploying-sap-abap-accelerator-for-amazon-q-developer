*----------------------------------------------------------------------*
* Table: ZSD_MGN_S3_LOG
* Description: Margin Data S3 Upload Log
*----------------------------------------------------------------------*
* This table logs all S3 upload activities from the margin data API.
* Use transaction SE11 to create this table in your SAP system.
*----------------------------------------------------------------------*

Table Name: ZSD_MGN_S3_LOG
Description: Margin Data S3 Upload Log
Delivery Class: A (Application Table)
Data Class: APPL0
Size Category: 0
Buffering: Not allowed

*----------------------------------------------------------------------*
* Field Definitions
*----------------------------------------------------------------------*

Field Name       Key  Data Element/Type     Length  Description
---------------  ---  -------------------   ------  --------------------------------
MANDT            X    MANDT                 3       Client
LOG_ID           X    SYSUUID_C32           32      Unique Log ID (GUID)
UPLOAD_DATE           SYDATUM               8       Upload Date
UPLOAD_TIME           SYUZEIT               6       Upload Time
USERNAME              SYUNAME               12      User Name

*----------------------------------------------------------------------*
* TVARVC Configuration Required
*----------------------------------------------------------------------*
* The following TVARVC entries must be configured for S3 upload:
*
* Name                      Type  Description
* ------------------------  ----  ------------------------------------
* ZSD_MGN_S3_URL            P     S3 Gateway URL (e.g., https://your-api-gateway.execute-api.region.amazonaws.com/prod/)
* ZSD_MGN_S3_API_KEY        P     API Key for authentication (X-API-Key header)
* ZSD_MGN_S3_BUCKET         P     S3 Bucket name for logging purposes
*
* Use transaction STVARV to maintain these values.
